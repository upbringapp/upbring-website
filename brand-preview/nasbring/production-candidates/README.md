# Nasbring production candidates

These files are isolated production candidates derived from the approved Nasbring review artwork. They are not connected to the website.

## Palette

- Warm off-white: `#F5EEE2`
- Deep navy: `#242A46`
- Muted red: `#9B5658`

## Wordmarks

- `nasbring-wordmark-primary-navy.png` — deep navy wordmark on genuine transparency
- `nasbring-wordmark-tagline-review.png` — deep navy wordmark with the review-only muted-red line `quietly understood`
- `nasbring-wordmark-dark-background.png` — warm off-white wordmark on genuine transparency

The wordmark candidates preserve the approved high-resolution raster letterforms. No font file is embedded or bundled. Because the source reference is raster-only and the exact typeface is unconfirmed, these are production raster candidates rather than final trademark/vector masters.

## Production hold

No legacy asset has been removed or overwritten. No application source, metadata, asset reference, or public route points to these candidates.

## Asset preparation method

The approved generated review artwork was used as the source without further generative reinterpretation. Deliverables were produced by deterministic palette normalization, alpha-preserving recoloring, and high-quality downsampling from the largest approved source. No additional image-generation prompt or external font was used for this production-candidate pass.
