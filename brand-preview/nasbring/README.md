# Nasbring brand preview

Review-only raster candidates derived from the founder-supplied Nasbring visual dated 2026-08-22. These files are not connected to the application and are not production brand masters.

## Candidate palette sampled from the reference

- Warm off-white: `#F5EEE2`
- Deep navy: `#242A46`
- Muted red: `#9B5658`

The exported artwork uses these flat sampled values. No gradient, shadow, texture, or additional marketing copy is included.

## Typography direction

The reference appears to use a distinctive lowercase slab/transitional serif wordmark with a single-storey `g`, paired with a small, widely tracked sans-serif tagline. The exact typeface cannot be identified reliably from the raster reference. These candidates therefore preserve the visual character without bundling or claiming an unverified font. A final production wordmark should be redrawn as approved vector artwork or rebuilt from a confirmed, properly licensed typeface.

## Generation notes

Mode: new image generation, one asset direction per call, using the supplied reference as the sole visual source. Prompts specified the exact text, lowercase treatment, reference hierarchy and spacing, sampled color roles, true transparency where required, and exclusions for gradients, shadows, mascots, unrelated symbols, startup styling, and extra copy. Exports were normalized to the sampled flat palette and requested delivery dimensions.

The favicon and touch-icon directions use the wordmark's lowercase `n` rather than shrinking the full name or introducing a new symbol. The favicon version fills more of the canvas for 16 px and 32 px recognition; the touch icon retains a wider safe area.

## Production hold

The candidate tagline `quietly understood` is present only in the two review creatives that call for it. No website, metadata, email, or production asset currently references this folder.
